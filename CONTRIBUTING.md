# Contributing to Murmurwell

Thank you for helping make dictation more transparent.

1. Search existing issues, then open one for substantial cleanup-rule changes.
2. Fork the repository and create a focused branch.
3. Run `npm ci`, then `npm run dev`.
4. Add or update tests in `src/domain.test.ts` for transformation changes.
5. Run `npm run check`.

By contributing, you agree that your contribution is licensed under MIT.
